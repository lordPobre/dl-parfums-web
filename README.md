# DL Parfums - Catálogo de Alta Perfumería 💎

Plataforma web minimalista y elegante desarrollada en Django para la gestión y visualización de un catálogo de alta perfumería. Diseñada para ofrecer una experiencia de usuario (UX) inmersiva, con integración de atención directa por WhatsApp.

## 🚀 Características Principales

* **Diseño Frontend de Alta Gama:** Interfaz construida con Tailwind CSS, utilizando paletas monocromáticas, tipografías Serif elegantes (Playfair Display) y diseño 100% responsivo.
* **Catálogo Dinámico:** Filtrado de productos por marca y sistema de productos destacados en la página principal.
* **Venta Directa (Frictionless):** Botones de acción integrados con la API de WhatsApp, pre-llenando el mensaje con el producto exacto seleccionado por el cliente.
* **Backoffice Moderno:** Panel de administración potenciado por Jazzmin, ofreciendo una gestión de inventario limpia, rápida y amigable.
* **Logística Local:** Sistema de políticas de entrega adaptado para retiros en showroom o puntos coordinados dentro de Castro.

## 🛠️ Tecnologías Utilizadas

* **Backend:** Python 3, Django
* **Frontend:** HTML5, Tailwind CSS (CDN), Google Fonts
* **Base de Datos:** SQLite (Entorno de desarrollo)
* **Panel de Administración:** Django Jazzmin
